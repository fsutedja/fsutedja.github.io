# freya

My personal site: real-looking gems scattered on paper around "hi, i'm freya".
Plain HTML, CSS and JavaScript, no installs needed.

## Preview it on your computer

The gems need a tiny local server (browsers block the effect if you double-click `index.html`).

1. Open Terminal in this folder.
2. Run: `python3 -m http.server 8000`
3. Open http://localhost:8000
4. Add `?tune` to the address (http://localhost:8000/?tune) to show the design sliders and font switcher.

## What each file does

| File | What it's for | Edit it? |
|---|---|---|
| `index.html` | The page, its styles and the gem animation loop | sometimes |
| `js/content.js` | All the words: intro, links, projects, skills, places | **yes, this is the main one** |
| `js/gems.js` | The gem list (positions on the gem sheet) and how they're scattered | rarely |
| `js/facets.js` | Finds each gem's facets and lights them live | no |
| `images/gem-sheet.png` | The gem photo sheet (AI-generated by me) | swap for a new sheet |
| `images/world.svg` | World map for "places i've visited" (Natural Earth, public domain) | no |

Every visit shows a new random arrangement. Add `?seed=27` (any number) to pin one.

## Publish

The site is served by GitHub Pages from the `main` branch.

## After changing a file

The `?v=…` numbers on the scripts in `index.html` make browsers fetch the new version right away.
When you change a file in `js/`, bump its number (any new number works).
